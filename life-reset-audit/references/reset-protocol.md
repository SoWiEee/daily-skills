# 三階段人生重啟流程

## 使用方式

這是一個可選的一日流程，不是每次對話都必須完成的問卷。使用者可以：

- 在一天內分早上、白天、晚上完成。
- 和 agent 分幾次互動。
- 只做其中一段，例如只做 Vision 或只做晚上收斂。
- 先自己寫，再把答案帶回來請 agent 協助整理。

agent 的工作是幫忙拆題、追問、辨認矛盾和整理；不要替使用者直接寫出他的人生答案。

開始前先問兩件事：

1. 使用者現在有足夠空間思考嗎？如果已經強烈自責、羞愧或焦慮，先轉交 [`ease-inner-conflict`](../../ease-inner-conflict/SKILL.md)。
2. 使用者想要互動陪跑，還是拿一份自主工作表？

## 第一段：早上，心理挖掘

目標不是立刻找出終極答案，而是讓目前的生活 trajectory 變得可見。

### A. 找出正在容忍的事

先選 1–3 題，不要全部問完：

- 哪一種持續存在的不滿，你已經習慣到不太再把它當問題？
- 過去一年你最常抱怨哪三件事？
- 如果有人只觀察你的行為，不聽你的解釋，他會認為你目前正在把什麼放在第一位？
- 目前生活中，有哪個事實是你不太想讓自己尊敬的人知道的？
- 你正在等待什麼條件出現，才允許自己開始？

整理時分開：

- 使用者明確說的願望。
- 行為實際穩定產生的結果。
- 目前仍需要測試的解釋。

### B. 建立 Anti-Vision

先從「普通星期二」開始，不要求戲劇化：

- 如果目前的生活方式再持續 3–5 年，你在哪裡醒來？
- 你的身體、注意力和能量是什麼狀態？
- 早上第一個念頭是什麼？
- 白天大部分時間花在哪裡？
- 晚上回到家時，什麼感覺最熟悉？

只有使用者狀態穩定且想繼續，才追加：

- 如果再過十年仍沒有改變，哪些機會可能縮小？
- 你會變得特別擅長容忍什麼？
- 如果一輩子都選最安全的版本，你可能沒有讓自己嘗試、感受或成為什麼？

最後壓縮成一句話：

> 我不想讓生活繼續變成＿＿＿＿。

完成後做效果確認。如果壓力上升，停止延長時間範圍，改做當下的一個具體卡點，或轉交 `ease-inner-conflict`。

### C. 找出正在保護的東西

不要問「你真正害怕的是什麼」並替使用者回答。改用假設：

- 如果真的改變，哪個自我描述可能要鬆動？
- 維持現在的做法，短期讓你免於什麼？
- 你可能正在保護安全感、自尊、歸屬感、選擇權、便利性、名聲或可預測性中的哪一項？
- 還有沒有一個不涉及心理防衛的解釋，例如疲勞、技能不足、任務太大或資源不夠？

至少保留兩個競爭假設，並為每個假設設計一個低成本測試。

### D. 建立 Vision

請使用者描述 2–3 年後一個想長期過下去的普通星期二：

- 在哪裡生活？
- 大部分時間投入什麼工作或學習？
- 身邊有哪些人？
- 哪些事不再佔用注意力？
- 哪些選擇可以自己決定？
- 哪些不舒服的代價仍然願意承擔？
- 什麼條件會讓這種生活可以維持很多年？

接著請使用者自己完成：

> 我是會在＿＿＿＿時，持續做＿＿＿＿的人。

最後問：

> 如果你已經是這種人，這星期會做哪一件小事？

## 第二段：白天，打斷自動導航

這一段的重點是觀察真實行為，不是繼續寫更多理論。可以把 2–4 題設成提醒，或在走路、通勤、等待時使用：

- 我現在正在做什麼？它把我帶向 Vision，還是 Anti-Vision？
- 我現在做這件事，是在靠近某個結果，還是在避免某種不舒服？
- 如果有人看完我過去兩小時的行為，他會認為我真正重視什麼？
- 哪件重要的事，我一直假裝它不重要？
- 我現在是在保護舊的自我描述，還是在練習新的生活方式？
- 今天什麼時候最有生命力？什麼時候最麻木？
- 現在能做的最小版本是什麼？

不要要求使用者每次都做出正確選擇。只要記下一兩筆實際資料，晚上再看即可。

## 第三段：晚上，整合成可行系統

先問：

- 今天哪一個觀察最出乎意料？
- 現在看起來，自己卡住的原因有哪些可能？
- 哪個假設有資料支持？哪個只是聽起來合理？

再完成兩句壓縮版：

> 我拒絕讓生活變成＿＿＿＿。

> 我正在建立＿＿＿＿的生活。

最後依序整理：

1. **一年結果**：一年後出現什麼可觀察的結果，代表舊 pattern 真的開始鬆動？
2. **一個月專案**：一個月後要完成什麼作品、資料、技能或探索，讓一年結果仍然可能？
3. **接下來七天**：哪一個承諾會讓下一週和這週不同？
4. **明天**：只安排 2–3 個這個新方向的人會做的行動。
5. **回饋**：要記錄什麼 leading indicator？何時回來檢查？

### 可選：遊戲化語言

使用者喜歡遊戲比喻時，才使用這張對照表：

| 人生系統 | 遊戲語言 | 要回答的問題 |
|---|---|---|
| Anti-Vision | Stakes | 我不想讓生活變成什麼？ |
| Vision | Win condition | 我想建立什麼生活？ |
| 一年結果 | Mission | 今年要推進到哪裡？ |
| 一個月專案 | Project | 現在要完成什麼可交付成果？ |
| Daily levers | Quests | 哪些重複行動真正推進結果？ |
| Constraints | Rules | 哪些代價我拒絕支付？ |

不要為了讓人生「像遊戲」而新增不必要的徽章、積分或懲罰。這張表只是幫助使用者看清層級。
