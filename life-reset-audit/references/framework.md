# 人生重啟審視：概念與限制

## 這套工具在做什麼

這個 Skill 把四個反思工具放在同一個可回饋的流程裡：

1. **行為證據**：觀察目前的環境、獎勵、習慣、摩擦和擔心，正在把使用者推向哪裡。
2. **Anti-Vision**：描繪目前 trajectory 延續下去後，使用者不想要的普通生活。
3. **Vision 與 Identity**：描述一個想長期過下去的普通生活，以及會讓它逐漸變得可能的重複行為。
4. **回饋控制**：行動、觀察、比較、調整，再重新嘗試。

概念鏈可以寫成：

`目標 → 注意什麼 → 採取什麼行動 → 得到什麼回饋 → 形成什麼自我描述 → 產生下一個目標`

介入時不要試圖一次改完所有東西，而是：

`觀察 → 找出矛盾 → 選擇暫定方向 → 設定限制 → 做可逆承諾 → 記錄 → 更新`

## 需要主動修正的地方

### 重複行為不等於真正願望

使用者可能一方面真心想在學業上成功，另一方面卻反覆逃避讀書。這可以由疲勞、任務設計、焦慮、技能不足、環境摩擦、即時獎勵或資源不足解釋。

可以說：

> 你的行為顯示，目前的生活系統比較穩定地獎勵了某件事。

不要說：

> 你其實想要失敗。

行為提供的是線索，不是對使用者內心的判決。

### Identity 可以幫助行動，也可能困住行動

可觀察的行為身份可以幫助使用者把 Vision 接回日常：

> 我是會在不確定時先做小實驗的人。

但固定身份標籤可能變成自我實現的預言：

> 我就是懶惰的人。
> 我天生不適合這條路。
> 我就是不擅長社交的人。

每個身份句都要問：什麼資料會支持它？什麼資料會推翻它？它是不是只是在描述一段期間的行為？

### Anti-Vision 是邊界，不是恐懼行銷

Anti-Vision 的用途是幫助使用者知道不想再沿著哪條 trajectory 前進，不是把最糟的情況寫得越痛苦越有效。

預設使用普通日子的描述；只有使用者狀態穩定且主動想深入，才追加十年或人生終點的問題。若練習後羞愧或焦慮上升，停止深挖，轉交 [`ease-inner-conflict`](../../ease-inner-conflict/SKILL.md)。

### 失敗先當成系統資料

一次沒有做到，可能表示：

- 沒有執行原本的行動。
- 行動的阻力太高。
- 策略沒有帶來預期的 leading indicator。
- 環境或資源沒有配合。
- 對目標、受眾或因果關係的假設錯了。
- 這個目標本身並不適合目前的人生階段。

先找出是哪一層出了問題，再決定要調整哪裡。不要把系統回饋直接翻譯成「我不夠好」。

## 來源中保留與不保留的內容

這個 Skill 保留原文的實用骨架：

- Identity 會影響注意力與行動。
- 行為證據可以用來檢查 stated preference 和 revealed preference 的落差。
- Anti-Vision 和 Vision 都應該描述普通生活，而不只是抽象成就。
- 目標要一路降到一個月專案和明天的行動。
- 方向必須透過 feedback 不斷修正。

以下內容只當背景，不作為 agent 的判斷規則：

- 所有行為一定都有單一的隱藏目標。
- 一天可以完成 identity shift。
- 九階段心智發展可以準確分類一個人。
- 只要願望夠強，任何目標都一定能達成。
