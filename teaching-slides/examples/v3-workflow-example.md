# v3 Workflow 範例

使用者需求：把一章 Kubernetes Scheduling 筆記做成 80 分鐘課程。

## 階段 0

先確認學生是否已經知道 Pod、Node、Resource Request 與 Scheduler 基本角色，再確認課後是否要自讀。

## 階段 1

```text
S1 為什麼需要 Scheduling
S2 Filter 與 Score 的 Mental Model
S3 Resource Request 與 Fit
S4 Worked Scheduling Example
S5 Failure / Pending Pod
S6 Recap + Check
```

## 階段 2 文稿樣稿

挑 S2 Concept、S4 Worked Example、S5 Failure、S6 Check 各一張，先確認文稿語氣與深度。

## 階段 3 Storyboard

S2 可能路由成：

`ordered mechanism → Process Flow → G16 → horizontal full-canvas → anchor`

S4 可能路由成：

`state + resource allocation → Trace + Allocation Blocks → G26 → dense`

## 階段 4 Demo

實作 Section Divider、Process Flow、Worked Example、Check 共四張。

## 階段 5

Demo 核准後寫入 Design Lock。

## 階段 6

生成完整 Deck。

## 階段 7

檢查 Learning Goal Coverage、Overflow、Rhythm、Style Drift 與 AI 味。
