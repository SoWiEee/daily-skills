# Citation 規則

教學簡報採簡短、可追查的來源標示。

建議格式：

- `Source: Apple Platform Security`
- `[NVIDIA CUDA Guide]`
- `Data: MLPerf Training v5.0`

HTML / React 能加連結時，把來源文字做成 Hyperlink。長 URL 不要直接佔據主要版面。

Evidence Page 的 Source 要靠近 Evidence。外部統計、論文 Figure、新聞 Screenshot、Benchmark 與產品畫面都要保留來源。

模糊歸因不接受。不能只寫「研究顯示」或「業界認為」。
