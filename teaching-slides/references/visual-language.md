# Visual Language

- 關係用 Diagram 說明，裝飾不取代資訊結構。
- Coral Accent 用在主要 Teaching Focus；其他 Accent 維持固定 Category 語意。
- Command、Identifier、Code Label 與技術 Metadata 可以使用 Monospace。
- 有主次時優先 Asymmetric Composition。
- Ghost Numeral 或大型幾何只放 Section / Anchor 類頁面。
- Source 要能讀，但視覺權重低於內容。
- 避免 Generic Icon Row、Glassmorphism、Pill-heavy Dashboard、Gradient Blob。
- 不用相同 Card Grid 填滿每一張頁面。
- Diagram 的箭頭與 Boundary 都要有語意。
