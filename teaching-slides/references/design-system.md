# Design System

這份 Design System 延續使用者提供的技術簡報風格。除非使用者另有指定，視覺語言維持深色、技術感、高對比與少量強 Accent。

## Canvas

- 1920×1080
- Safe Margin：水平 112px、垂直 88px
- Default Gap：40px

## Palette

- Background：`#221C34`
- Foreground：`#F8F6FB`
- Muted：`#B9B1C6`
- Primary Accent：`#FF595A`
- Violet：`#8A70FF`
- Cyan：`#18C5C8`
- Orange：`#F2A65A`
- Border：`rgba(248,246,251,.16)`
- Surface：`rgba(255,255,255,.045)`

Accent 要有固定語意。不要為了每頁看起來「更豐富」而新增顏色。

## Typography

建議：

- 繁體中文 Body：Noto Sans TC 或專案既有的易讀 CJK Sans
- Display：有技術感的 Condensed / Narrow Sans，有現成字體再使用
- Mono：JetBrains Mono

字級參考：

- Hero：86–112px
- Section：64–84px
- Slide Title：48–60px
- Lead：38–48px
- Body：28–34px
- Table：23–27px
- Source：18–21px
- Code：24–30px

## Shape Language

- Radius：4–10px
- Border：細、低對比
- Shadow：少用
- Gradient：預設關閉
- Card：只有 Category 或明確 Structural Group 才使用
- Rule、Bracket、Label、Terminal Motif 與 Ghost Geometry 少量使用

## Hierarchy

每頁至少要看得出三層：

1. Primary Focal Point
2. Supporting Explanation / Evidence
3. Metadata / Source

不要讓所有元素都有同樣大的視覺權重。
