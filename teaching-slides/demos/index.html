Teaching Slide Grammar
G12

Matched Comparison

兩個概念採相同維度與順序並列，讓差異直接成為畫面結構。

G10

Layer Stack

用於權限邊界、Protocol Stack、抽象層與分層防禦。

G16

Process Flow

流程、Pipeline 與生命週期用方向與 Stage 表達。

G26

Worked Example

把中間 State 與推理步驟留下，讓學生能重建答案。

G25

Code Walkthrough

只放要講的 Code，加 1 到 3 個 Callout 與 Runtime 結果。

G04

Recap Map

用概念圖、因果鏈或矩陣重新組織已教內容。
