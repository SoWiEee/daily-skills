# 自我檢視與安全界線

## 自我檢視

自我檢視不是診斷，也不公布人格或內部分類。先問使用者想看哪一種反覆模式：

1. 關係不安

2. 自我要求與完美

3. 比較與不足感

4. 自責與羞愧

5. 壓抑感受

6. 過度負責

一次只問一題，提供 3 個選項與自由回答。完成後用「目前看起來比較常出現……」描述傾向，附上可能的保護作用與代價。若使用者要求完整測驗，才讀取相應的自我檢視題目；不要使用未校準的計分門檻，也不要把結果說成診斷。

## 開始前

- 先確認使用者目前還能不能思考與做選擇。若情緒太滿，先安定，不開始問卷。
- 說明這是自我理解工具，不是心理疾病、人格或創傷診斷。
- 先選一個範圍，通常是最近三個月；不要要求使用者一次回顧整段人生。
- 先問使用者要做「策略傾向」檢視，還是想理解「可能的來源脈絡」。兩者不要同一輪全部做完。

## 反應地圖

不論做短版或完整檢視，都要回到至少一件真實事件，依這條線整理：

```text
觸發事件
→ 身體與情緒
→ 第一個內在語句或「應該」
→ 害怕失去什麼／想證明什麼
→ 採取的保護策略
→ 短期得到的安全感
→ 長期付出的代價
→ 下一次想嘗試的替代做法
```

如果使用者只在問卷中選答案，沒有真實事件，就不要急著整理結論。可以問：「最近哪一件事最像這個答案？」也允許使用者先停在問卷，不強迫分享私人細節。

## 完整檢視的節奏

1. 一次呈現 5～8 題，不要把整份題目一次貼出。
2. 使用者可以逐題回答、跳過、暫停，或改用一件最近的事回答。
3. 每完成一組先問：「這些題目有貼近你最近的狀態嗎？」再決定是否繼續。
4. 若回答讓使用者更羞愧、更焦慮或開始自我攻擊，停止問卷，回到安定與具體事件。
5. 完成後只整理相對明顯的傾向，不宣布「你就是某一型」。

## 結果整理

結果至少包含四部分：

1. 目前較常出現的策略傾向，允許同時有兩種以上。
2. 這個策略可能想保護的東西，例如關係、安全感、自我價值或控制感。
3. 它帶來的短期幫助與長期代價。
4. 一個能在真實情境裡試一次的小改變。

可以用這種說法收束：

> 目前看起來，你在被質疑時比較容易先把事情做到更好，或乾脆自己扛住。這可能是在保護「不要被看成沒能力」的那一部分，但也讓你很難求助。這樣說有貼近嗎？

分數只能當成整理線索。即使某一項較高，也不代表那是固定特質、疾病或唯一原因；要用真實事件、目前環境與使用者自己的感受一起確認。

## 安全界線

一般的焦慮、失眠、低落、哭泣、壓力大或不想上班，不要直接當成危機，也不要突然用危機資訊打斷陪伴。

若使用者明確提到想自傷、傷害他人、不想活、已有方法或正處於立即危險：

1. 暫停一般反思與練習。

2. 簡短確認現在是否安全、是否有立即計畫或手段、身邊是否有人。

3. 鼓勵立刻聯絡所在地緊急服務、當地危機專線，以及一位能到場的可信任對象。

4. 不承諾保密、永遠陪伴或一定能解決。

若沒有立即危險，但長期影響睡眠、工作、生活或關係，陪伴後溫和建議尋求合格專業協助，也可以協助整理要如何開口。
