# 自我檢視題目

## 使用規則

這份檔案只在使用者明確要求完整自我檢視時讀取。它是自我理解工具，不是經過臨床驗證的量表，也不能用來診斷人格、創傷或心理疾病。

- 一次呈現 5～8 題，不要一次貼出全部題目。
- 使用者可以回答、跳過、暫停，或改用最近一件真實事件來談。
- 完成一組後，先確認題目是否貼近，再決定是否繼續。
- 結果只描述相對明顯的策略與可能來源，不公布固定類型。
- 分數只能當整理線索，不使用原始門檻宣稱嚴重程度，也不把高分解讀成診斷。

## 一、四種策略傾向檢視

### 回答方式

請使用者回想最近三個月，在壓力或關係事件中的狀態。每題使用五點回答：

```text
0 完全不符合
1 不太符合
2 不確定
3 有點符合
4 非常符合
```

### 題目

1. 即使不想答應，也很難說不。
2. 我習慣壓下不安，把表現做好再說。
3. 我寧可一個人，也不想面對人際的複雜。
4. 我常常想：「如果我不夠好，就會被討厭。」
5. 我覺得如果不反抗，就會被踩在腳底。
6. 我很難信任別人，即使表面上裝得很親切。
7. 我習慣什麼事都靠自己，不輕易求助。
8. 當情緒來的時候，我寧可轉移注意力。
9. 我不喜歡被批評，會立刻想反擊或辯解。
10. 我常常覺得：「再撐一下就好。」
11. 我傾向懷疑權威或規則，認為它們限制人性。
12. 與人親近會讓我感到不自在或有壓力。
13. 我不太知道如何表達真正的需要與想法。
14. 就算累垮，我也會逼自己完成責任。
15. 被別人肯定的時候，我才覺得自己有價值。
16. 如果我不努力，就覺得自己沒有價值。
17. 當我感覺被冒犯時，我會直接表達不滿。
18. 我覺得依賴別人會讓自己變得很弱。
19. 我很容易感受到不公平，並為自己爭一口氣。
20. 我常常壓抑情緒，讓自己看起來成熟懂事。
21. 我常常覺得情緒沒有用，只會讓事情更糟。
22. 我總是先看別人眼色，再決定自己要做什麼。
23. 面對衝突，我會想要趕快解釋和彌補。
24. 別人問我在想什麼時，我會下意識說「沒事」。
25. 當我感覺被否定時，會立刻激起怒氣。
26. 遇到問題我傾向自己處理，不說出來。
27. 我擔心關係會突然中斷，所以總是小心翼翼。
28. 我會不自覺微笑，來淡化自己真正的感受。
29. 我很怕讓別人失望，總會先考慮別人的期待。
30. 我討厭服從，寧願做出反方向的選擇。
31. 只要別人生氣，我就會懷疑是自己的錯。
32. 放鬆會讓我感到焦慮或罪惡。
33. 我常常覺得別人想控制我，讓我不舒服。
34. 我習慣假裝沒事，避免被人看穿。
35. 情緒對我來說，是浪費時間的東西。
36. 我會為了完成工作，犧牲休息與人際。
37. 我寧願當壞人，也不想讓別人有優越感。
38. 我說話常常帶刺，但我覺得這是真誠。
39. 我很怕自己看起來脆弱或沒能力。
40. 我總是在解決問題，而不是表達情緒。

### 整理方式

依照下列題號加總，可以看出目前較常使用的策略方向。不要把最高分叫成「人格」，也不要只看分數下結論；一定要回到一件真實事件確認。

| 暫時稱呼 | 題號 | 可以觀察的方向 |
| --- | --- | --- |
| 迎合策略 | 1、4、15、20、22、23、27、28、29、31 | 先照顧他人反應，換取關係安全或避免失望 |
| 獨撐策略 | 2、7、10、14、16、32、35、36、39、40 | 靠表現、控制和自己扛住，避免被看成沒能力 |
| 抽離策略 | 3、6、8、12、13、18、21、24、26、34 | 拉開距離、切斷感受或避免依賴，減少受傷風險 |
| 對抗策略 | 5、9、11、17、19、25、30、33、37、38 | 先反擊、爭取或保持主導，避免被壓過或貶低 |

整理時要問：

1. 這個策略在什麼情境最容易出現？
2. 它當下想保護的是關係、安全感、自我價值，還是控制感？
3. 它讓使用者短暫得到什麼？長期又付出什麼？
4. 下一次能否保留一點原本的保護作用，同時少付出一點代價？

## 二、三種來源脈絡檢視

### 回答方式

這組題目不是要找出「問題源頭」，而是協助使用者看看目前的內耗，可能和哪種脈絡比較接近。每題使用四點回答：

```text
0 完全沒有
1 偶爾會
2 經常如此
3 幾乎總是
```

### 過往受傷與忽略經驗

1. 我常覺得自己表現得不夠好，容易自責。
2. 我害怕被責怪或讓人失望，因此常常過度準備或乾脆逃避。
3. 我很難相信自己值得被愛或被接納。
4. 我會過度努力來證明自己有價值。
5. 當我出錯時，我會覺得自己整個人都不好。
6. 我很常懷疑自己是否有能力完成一件事。
7. 我在意別人對我的看法，遠超過我對自己的評價。
8. 我常覺得自己必須獨自撐過一切，不能依賴別人。
9. 我常常安撫別人，但很難安撫自己。
10. 我覺得如果不夠堅強，就不值得被重視。
11. 我習慣壓抑自己的感受，不讓人知道我其實很受傷。
12. 我曾經在成長過程中被忽略、忽視或過度批評。

### 環境與比較壓力

13. 我很在意自己是否比別人慢、差或落後。
14. 當別人表現比我好時，我會對自己感到失望或焦慮。
15. 我覺得自己一直在跟世界競賽。
16. 我很少能真正感到滿足，因為總覺得還可以再更好。
17. 我覺得如果不表現得出色，就會被忽略或淘汰。
18. 我會在意他人是否看得起我、是否把我當一回事。
19. 我會因為害怕輸、怕被比下去而拖延或逃避。
20. 我容易過度努力，即使已經很疲憊也難以停下來。
21. 我有時會故意冷漠地面對競爭，內心卻很在意。
22. 我討厭輸，但更害怕證明自己不夠好。
23. 我常常為了達到外在的成功標準而忽略自己的感受。
24. 我覺得環境只看效率與成就，讓我很難真正放鬆。

### 角色與責任期待

25. 我覺得身為專業工作者，應該一直保持冷靜、理智，不能出錯。
26. 我會強迫自己隨時待命，因為我相信這是職責的一部分。
27. 我會對自己的情緒與需求感到羞愧，因為我覺得專業者不應該那麼情緒化。
28. 我覺得別人總是期望我強大、穩定、有能力，不應該讓人看到脆弱的一面。
29. 我覺得如果沒有即時幫助他人，就會被認為不夠稱職或不夠有愛心。
30. 即使已經沒有能力處理更多事情，我還是很難說「我無法負荷」。
31. 我覺得自己身為長姊、哥哥或母親，就應該更成熟、更犧牲。
32. 我對自己有一套很嚴格的標準，因為這是我身為某個角色的價值體現。
33. 我擔心表現出負面情緒會讓人覺得我不負責或不稱職。
34. 我認為如果不能照顧好所有人，就是我不夠好。
35. 我經常忽略自己的需求，因為我覺得這個角色不應該有太多情緒。
36. 我覺得自己不應該喊累、喊痛或說不行，因為那會讓人失望。

### 整理方式

比較三組分數時，只把它當成「目前比較容易被哪種脈絡觸發」的線索：

- 過往經驗分數較高：可以問目前事件是否帶來熟悉的被忽略、被否定或被拋下感；不直接宣布有創傷。
- 環境壓力分數較高：可以問比較、效率、競爭或長期高壓是否仍在生活中發生。
- 角色期待分數較高：可以問哪些「應該」來自職業、家庭位置或社會期待，哪些是使用者現在仍願意選擇的價值。

如果三組都高，先回到一件最近的事件，不要用結果解釋整個人生。完成後整理「目前最容易被碰到的脈絡、它帶來的內在語言、可做的一個小調整」，並問使用者是否貼近。
