# 關係焦慮練習庫

## 使用時機

只有在使用者準備做練習、準備一段對話、需要拒絕、想復盤，或已經能穩定描述事件時讀取。一次選一個最符合當下狀態的練習；不要把整份練習庫一次貼出。

## 一、焦慮覺察五問

適合：使用者只說「我很焦慮」，但還不清楚焦慮的來源。

1. 外在發生了什麼事？只寫可觀察的事件。
2. 身體出現什麼反應？
3. 我當時有什麼情緒與想法？
4. 我採取了什麼因應行為？
5. 這個行為真的處理了問題，還是只讓我暫時安心？

如果使用者願意，再加問：「我真正害怕或想控制的是什麼？」不要一次要求使用者回溯所有過去經驗。

## 二、表層情緒與底層需要

適合：使用者正在生氣、指責、羞愧或反覆確認，但想理解反應底下的需要。

```text
我表面上感受到：
我身體出現：
我腦中出現的解讀：
我可能害怕：
我可能需要：
我希望用什麼方式表達，而不是直接反應：
```

提醒使用者：這些只是可能的方向，不是心理診斷。可以提供兩至三個選項，請使用者判斷哪一個比較接近。

## 三、事實、解讀與預測分開

適合：等待回覆、看到冷淡訊息、被批評、或不確定對方意思時。

| 類別 | 問題 |
| --- | --- |
| 事實 | 我能用錄音或旁觀者觀察確認什麼？ |
| 解讀 | 我認為這代表什麼？ |
| 預測 | 我害怕接下來會發生什麼？ |
| 其他解釋 | 還有哪些同樣符合目前事實的可能？ |
| 下一步 | 我能直接詢問、暫停觀察，或先照顧自己什麼？ |

不要用「換個角度想」否定使用者的感受；先承認不確定真的不舒服，再協助擴大解釋範圍。

## 四、內在「應該」與自我批評

適合：使用者因拒絕、失誤、讓人失望或沒有達到完美標準而罪惡感很強。

1. 內在批評者原句是什麼？盡量寫出原話。
2. 它把我貼上了什麼標籤？
3. 這個標籤是可驗證的事實，還是過去為了避免被否定而形成的保護方式？
4. 這個標準有清楚、合理而且可達成的判準嗎？
5. 如果朋友遇到同樣的事，我會怎麼對他說？
6. 我可以用哪一句具體而支持性的話取代它？

可以使用：「這次沒有做到，不代表我整個人不好。我先處理下一個能做的小步驟。」但要依使用者自己的語氣調整，不要強迫正向思考。

## 五、情緒界限自我檢查

適合：使用者容易照顧別人、難以拒絕、對方不開心就自責，或想知道自己是否過度承擔。

請使用者選出最近常出現的項目：

- 我很在乎別人的感受，卻很少問自己需要什麼。
- 我覺得自己不重要，或必須有功能才值得被喜歡。
- 我很在意他人評價，很難承受被討厭。
- 我很難說不，常常先答應再後悔。
- 對方不開心，我就覺得自己做錯了。
- 我習慣委屈自己，讓事情表面上保持平靜。

接著只挑一個事件，問：

1. 這是我的責任、對方的責任，還是雙方可以協商的部分？
2. 如果我不立刻滿足對方，最實際的後果是什麼？
3. 那個後果是危險、關係變化，還是短期的不舒服？
4. 我願意承受哪一種短期不舒服，換取更多自主權？

## 六、停—看—應：中斷一輪互動循環

適合：使用者正要立刻答應、回嗆、回訊息、追問或在衝突中失去控制。

### 停

- 暫時不答應、不回覆或不繼續爭論。
- 喝水、深呼吸、離開現場、去洗手間或在心裡數數字。
- 使用爭取時間的句子：「我需要想一想，晚點再回覆你。」
- 若要暫停對話，盡可能說明自己何時會再回來談；若安全有疑慮，先離開並尋求支援。

### 看

- 我現在的情緒、目的與身體狀態是什麼？
- 對方的目的是表達需要、尋求關心、控制、保護，還是目前無法確認？
- 如果答應，我需要犧牲什麼？如果不答應，我要承受什麼？
- 哪些是現在的事，哪些可能喚起過去的恐懼？
- 我的界限可以畫在哪裡？
- 這一輪是怎麼開始的？我的反應如何影響對方，對方又如何影響我？
- 有沒有第三個人被拉進來傳話、站隊或收拾情緒？
- 我現在承擔的，是自己的責任，還是正在替別人承擔他可以處理的部分？

### 應

選擇一個最接近自己目的的回應：詢問、同理、表達感受與需要、拒絕、提出替代方案，或在安全允許下約定稍後再談。回應前可以先預測對方可能如何反應，但要把它當成預測，不要當成事實。

## 七、衝突溝通四步驟

適合：使用者想把感受說清楚，不想用指責、反問或沉默處理。

1. **同理**：承認對方可能在乎的事情。例：「我知道你是關心我的狀況。」
2. **詢問**：了解要求或反應背後的原因。例：「你希望我這樣做，是因為擔心哪一部分？」
3. **表達感受與需要**：用「我」陳述，不把解讀包裝成事實。例：「當你用這種方式要求時，我會感到壓力。我需要一點時間整理，再一起討論。」
4. **提出做法**：給出具體、可協商的下一步。例：「你可以先告訴我最在意的地方，我們今晚八點再談。」

避免：

- 「你都……」「你每次……」等概括與攻擊。
- 「你為什麼要……」等把情緒藏在反問裡的句子。
- 尚未理解就立刻說教、解決問題或要求對方不要有情緒。

## 八、伴侶或重要他人有情緒時

適合：使用者不知道該安慰、解決、給空間或設界限。

先問自己：

- 我是否因為害怕對方不開心，就急著讓對方恢復平靜？
- 對方現在需要的是傾聽、理解、空間還是具體協助？我是否真的知道，還是可以直接問？
- 我可以陪伴什麼？哪些仍然要由對方自己處理？

可用句子：

- 「你現在希望我先聽你說，還是一起想辦法？」
- 「我願意和你一起面對，但我現在沒有辦法替你把這個情緒處理掉。」
- 「我知道你需要一點時間；請告訴我你大概什麼時候準備好，我希望我們不要讓這件事一直懸著。」

## 九、練習拒絕與軟釘子

適合：使用者不敢拒絕、常立刻答應，或擔心別人失望。

先練習不立即答應：

- 「我需要想一想，再告訴你。」
- 「我現在還不能答應，我確認一下時間和能力後回覆。」
- 「我目前沒有辦法做完整的部分，但可以提供這一小段協助。」
- 「這件事不在我目前能承擔的範圍內，我需要拒絕。」

練習時不要把「對方不開心」當成自己失敗。成功標準是：使用者有爭取思考空間、說出真實界限，並依實際後果做選擇，而不是對方一定接受。

## 十、事後復盤

適合：對話結束後仍反覆想、後悔、羞愧或想知道下次怎麼做。

1. 事情實際怎麼發生？
2. 哪一個訊號最早提醒我正在焦慮？
3. 我採取了哪一個生存反應？它短期保護了什麼？長期造成什麼？
4. 我有沒有把對方的情緒當成自己的責任？
5. 哪個地方我有保留自己的界限？哪裡可以更清楚？
6. 下次我想提早做哪一個小動作？
7. 我的反應讓對方接著怎麼做？對方的反應又怎麼影響我？
8. 這次有沒有第三個人被拉進來，或有人承擔了不屬於自己的責任？
9. 我這次的退開是暫停、為了安全，還是只是讓焦慮暫時消失？
10. 我原本預測會發生什麼？實際發生了什麼？下次要維持、調整或停止哪一個做法？

## 十一、自我支持練習

適合：使用者能安全地做書寫，想理解過去經驗如何影響現在。

寫下一段過去讓自己受傷或害怕的互動，控制在能承受的範圍內，依序回答：

1. 這件事如何影響現在的我？
2. 當時我經驗到什麼感受、想法與需要？
3. 這些經驗讓我形成什麼內在標籤或生存策略？
4. 如果把自己當成好朋友，我想對那個時候的自己說什麼？

如果回憶讓使用者明顯失控、解離、恐慌或感到不安全，停止練習，回到當下的穩定與支持，不要繼續深挖。
