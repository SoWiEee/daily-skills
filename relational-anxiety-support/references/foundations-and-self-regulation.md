# 焦慮覺察與自我調節基礎

## 使用時機

當使用者還說不清楚自己在焦慮什麼、身體反應很明顯、反覆思考卻沒有行動，或需要先理解自己的情緒與內在標籤時讀取。這些內容用來幫助覺察與練習，不是診斷工具。

## 一、情緒是訊號，不是命令

情緒可以先被視為提醒注意的訊號，而不是必須立即服從的命令：

- 恐懼可能提醒「我感覺不安全」或「我預期某種威脅」。
- 悲傷可能提醒失去、失望或重要需要沒有被滿足。
- 憤怒可能提醒界限被碰觸、期待落差或感覺不被重視。
- 羞愧可能把「這件事做不好」擴大成「我整個人不好」。

接納情緒不等於認同所有解讀，也不等於照著情緒行動。先讓感受被看見，再檢查它想提醒什麼，最後選擇合適的表達與行動。

### 表層與底層情緒

一個人可能用表層情緒保護不容易直接表達的底層情緒：

- 害怕被否定，先用憤怒責備別人。
- 感到受傷或羞愧，表現得冷漠、不在乎。
- 其實很悲傷，卻不停工作、開玩笑或找事做來避開感受。

不要直接告訴使用者「你真正的情緒就是……」。可以問：

1. 你現在最先感覺到的是什麼？
2. 這個情緒底下，還有沒有另一個更脆弱或更需要被照顧的部分？
3. 它可能在提醒什麼需要、恐懼或界限？
4. 你希望怎麼表達，才不會直接被情緒推著行動？

## 二、用冰山整理焦慮

焦慮事件可以先用以下層次整理：

```text
可觀察事件
    ↓
身體反應與表層情緒
    ↓
自動想法、解讀與預測
    ↓
核心恐懼、需要與內在規則
    ↓
生存反應與因應行為
```

例如「對方沒有回訊息」是事件；胸悶、緊張是身體與情緒；「他是不是不在乎我」是解讀；底層可能是害怕被遺棄；接著可能反覆傳訊息、監看狀態或假裝不在乎。每一層都要分開記錄，才不會把預測當成事實。

## 三、焦慮與恐懼

可用工作性區分協助使用者理解：

- 恐懼通常指向比較明確、當下的威脅。
- 焦慮常指向尚未發生、但可能發生的威脅，並包含對不確定性的想像。
- 適度焦慮可能提醒人準備、檢查風險或採取行動；當注意力過度集中在威脅上，焦慮可能反而降低判斷與處理問題的能力。

可以問：

- 我真正害怕的是什麼？
- 如果最糟的結果發生，最難承受的是哪一部分？
- 我現在做的事是在處理實際問題，還是在暫時安撫恐懼？
- 這件事有多少在我的控制範圍內？

## 四、焦慮覺察表

引導使用者回想一個近期事件，依序記錄：

| 面向 | 要記錄的內容 |
| --- | --- |
| 外在事件 | 發生了什麼可觀察的事？對方實際說了什麼、做了什麼？ |
| 身體 | 心跳、呼吸、胸悶、肌肉、腸胃、發冷、發熱或其他反應。 |
| 情緒 | 焦慮、恐懼、憤怒、羞愧、悲傷、緊張或失望。 |
| 想法 | 我怎麼解讀？我預測接下來會發生什麼？ |
| 需要與恐懼 | 我想保護什麼？害怕失去什麼？需要安全、尊重、確認、空間或選擇權嗎？ |
| 行動 | 我追問、討好、逃避、沉默、僵住、搜尋、過度準備或立刻答應了什麼？ |
| 效果 | 這個行動帶來短期安心嗎？長期是否增加焦慮、衝突、疲憊或失去選擇？ |

## 五、快速威脅反應

遇到威脅感時，人可能出現「戰、逃、僵、討好／擔憂」等反應。這些詞只用來描述暫時的行為，不代表特定腦區或固定人格：

- **戰**：攻擊、指責、控制、挑剔、要求對方立刻回應。
- **逃**：避開對話、過度忙碌、搜尋其他事情、假裝不在乎。
- **僵**：說不出話、卡住、無法決定、停止回應。
- **討好／擔憂**：先處理他人情緒、立刻道歉、過度準備、努力讓所有人滿意。

這些反應可能曾經有保護作用，但不代表現在每次都適合。可問：「這個策略現在真的在處理問題，還是只讓我短暫感覺安全？」

## 六、內在標籤與「應該」

焦慮常與對自己的評價和模糊的內在規則有關：

- 我應該讓所有人滿意。
- 我一定要表現得很好。
- 我不能讓別人失望。
- 我不可以拒絕別人的需要。
- 只要我一直想、一直準備，就能確保事情不出錯。

當這些規則出現時，使用以下問題檢查，而不是立刻把它判定為錯誤：

1. 這句「應該」的標準是什麼？有清楚判準嗎？
2. 它是我現在思考後選擇的價值，還是過去為了避免被否定而形成的保護規則？
3. 如果我沒有做到，實際會發生什麼？我預測的危險和可承受的不舒服有什麼不同？
4. 如果朋友遇到同樣情況，我會怎麼對他說？

## 七、接納與重新選擇

接納自己不是說所有行為都沒有問題，而是承認當下的情緒、需要與限制確實存在。可以把自我批判改成具體而支持性的提醒：

> 這次沒有做好，不代表我沒有能力。我可以先處理下一個小步驟。

覺察後要回到選擇：

- 我現在能做什麼？
- 哪些事情不在我的控制範圍？
- 我要保護的界限是什麼？
- 我願意承受哪一種短期不舒服，換取長期的自主與一致？

一次只練習一小步，不要求使用者立刻改變所有反應。
