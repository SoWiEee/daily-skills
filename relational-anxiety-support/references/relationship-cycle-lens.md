# 關係循環觀察手冊

## 使用時機

只有在以下條件大致成立時才讀取：

- 使用者已說清楚一件具體的互動。
- 目前沒有立即危險，或安全問題已先處理。
- 使用者想理解一種反覆出現的互動，而不只是要一句回覆。
- 使用者仍有足夠空間描述事件，不是在情緒最高點。

這份手冊是給 agent 的內部觀察工具。不要向使用者說出理論名稱、概念名稱或「你屬於哪一型」，也不要把觀察結果當成診斷。

## 核心想法

不要只問「誰對誰錯」，也要看一個人的反應如何影響另一個人，最後又如何回頭加強原本的害怕：

```text
外在事件
→ 我的解讀
→ 我的反應
→ 對方的反應
→ 雙方更相信原本的預測
```

這是一個暫定的工作模型。若資料不夠，直接寫「目前無法確認」，不要用理論補空白。

## 七個觀察角度

不需要全部使用。每次挑最符合當下的一至兩個角度。

### 1. 我能不能保留自己的判斷

觀察使用者是否因為對方失望、生氣、沉默或否定，就立刻放棄自己的想法，或反過來試圖強迫對方接受自己的想法。

可以問：

- 如果對方不高興，我仍然知道自己想要什麼嗎？
- 我現在是在表達自己的立場，還是在讓對方趕快恢復平靜？
- 我能不能承認對方不同意，同時不把自己的選擇交出去？

這不是要求使用者變得冷漠，而是幫他找回「我可以在乎你，也可以保留我的判斷」的空間。

### 2. 有沒有第三個人被拉進來

觀察兩個人的壓力是否透過第三個人、群組、孩子、同事或親友來傳遞、站隊或分擔。

可以問：

- 有沒有人被要求傳話、評理或選邊？
- 這個第三人是在提供必要的安全支援，還是在替兩邊承擔原本該直接處理的壓力？
- 如果不把第三個人拉進來，兩個人需要直接說清楚什麼？

不要把所有求助都視為問題。安全支援、專業協助和單純拉人站隊要分開看。

### 3. 壓力集中在哪段關係或哪個人

觀察家庭或親密關係的壓力，是否集中到伴侶衝突、某個孩子、某個「最需要被修理的人」，或某一段長期冷淡上。

可以問：

- 大家是不是把所有問題都歸到同一個人身上？
- 誰的情緒最常被優先處理？誰的需要最常被忽略？
- 當整個家庭或關係壓力升高時，問題會集中在哪裡？

不要據此判定誰是問題來源。這個角度只是提醒 agent：表面上的「某人有問題」，可能同時承載了整段關係的壓力。

### 4. 有人是否越做越多，另一個人越少承擔

觀察過度承擔與依賴是否互相強化：一個人因為怕出錯而全部接手，另一個人因此更少練習負責，接著前者更不放心。

可以問：

- 我替對方做了哪些原本可以由對方承擔的事？
- 我不接手時，最實際可能發生什麼？
- 我是在提供合理協助，還是在替對方避免所有後果？
- 我可以少承擔哪一小部分，同時保留必要的安全與品質？

這一角度不能用來責怪照顧者，也不能在有真正權力不對等或安全風險時要求受害者「放手讓對方負責」。

### 5. 家庭或過去經驗是否影響現在的反應

只有使用者主動想理解長期模式時，才詢問：

- 這種「我必須討好／照顧／退開／保持安靜」的位置，以前在家裡出現過嗎？
- 這種反應是否也在其他重要關係中出現？
- 家人曾經教會我哪些「一定要」「不能」「不然就會怎樣」？

過去的相似之處只能提供線索，不能直接證明現在的問題是家庭造成的，也不能要求使用者回溯所有童年經驗。

### 6. 退開是暫停、安全距離，還是只剩消失

把三件事分開：

- **健康暫停**：說明需要空間，並在可以的時候回到議題。
- **安全距離**：為了避開威脅、羞辱、暴力或持續控制而降低接觸。
- **只靠切斷來止住焦慮**：每逢壓力就消失、拒絕所有重要對話，卻沒有讓問題更清楚。

可以問：

- 我現在退開，是為了整理、保護安全，還是因為完全承受不了對方的情緒？
- 我能否說明「我需要暫停」以及之後如何處理？
- 如果關係是安全的，我能不能在保留距離的同時說清楚自己的立場？

若有暴力、威脅或控制，安全優先，不把保持聯絡或回來談當成必要目標。

### 7. 更大的環境是否正在放大焦慮

把同樣的觀察放到職場、學校、家庭群組或社群：

- 整個環境是否都在催促、比較、監控或要求站隊？
- 壓力升高後，是否出現更多微管理、甩鍋、無效規則或不容許不同意見？
- 這是個人的反應，還是環境真的正在讓所有人更難冷靜？

不要把結構性問題縮成「你太敏感」，也不要把所有不舒服都歸咎於群體。

## 從觀察到行動

完成一至兩個角度後，使用以下小流程：

### 停

先不立即答應、反擊、追問或完全消失。必要時使用一句爭取時間的話：「我需要想一下，晚點再回覆。」

### 看

寫下：

- 我知道的事實。
- 我對這件事的解讀。
- 我害怕接下來發生什麼。
- 哪些責任是我的，哪些不是我的。
- 哪一個反應正在讓循環繼續。

### 選

只選一個自己能控制的改變，例如：

- 少替對方傳一次話。
- 不在當下答應，改成稍後回覆。
- 把自己的立場說清楚一次。
- 只協助一部分，不全部接手。
- 在安全允許下，說明暫停和回來談的時間。

### 試

先預測對方可能的反應，但只當成預測，不當成事實。對方可能更焦慮、追問、失望或退開，也可能沒有想像中嚴重。

### 回看

事後檢查：

- 實際發生了什麼？
- 我的預測哪些準確，哪些不準？
- 焦慮有沒有下降，還是只是暫時停止刺激？
- 責任是否變得更清楚？
- 這個做法要維持、調整或停止？

## 使用限制

- 不要把一次互動推論成固定性格或家庭真相。
- 不要使用專業概念替代具體事件與可觀察行為。
- 不要因為理解對方的焦慮，就淡化羞辱、威脅、控制或暴力。
- 不要把「改變自己的反應」說成使用者可以單獨修好整個關係。
- 不要在使用者情緒最高點要求做家庭史分析。
- 如果練習後使用者變得更自責、更羞愧或更焦慮，停止本手冊，轉交 [`ease-inner-conflict`](../../ease-inner-conflict/SKILL.md)。
